# 参画準備（2026-10-01〜10-04）と参画後の継続学習

公共系の更改案件（Java / TERASOLUNA / 結合試験フェーズ想定）に、サブリーダーとして入る前の4日間の計画と教材。

- **午前（座学）**: 会社資料の学習リスト22項目を、4日間で全部さらう

書籍は買わない前提。各項目に「書籍の代わりの要約（自作）」と「無料の公式ドキュメント・Web記事」を付けている。

## 1日の流れ

1. **午前（約3時間）**: 各項目の要約 → 公式・Web資料（指定した章だけ）→ 会社教材の該当コース
2. **午後（約3時間）**: 手順どおりに動かす → 改造課題 → 自分でレビュー
3. **締め（10分）**: 確認問題 → セッション締めの3問プロトコル → 一行ログ

確認問題の答えは `<details>` に入れてある。自分で書いてから開く。**午後の課題ではAIに聞かない**（詰まったら公式 → Javadoc → 最後にAI）。
