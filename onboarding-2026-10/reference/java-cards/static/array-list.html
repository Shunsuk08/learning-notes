配列と ArrayList

同じ「複数のデータをまとめる」でも、使いどころが違う
1配列とは
同じ型のデータを連続した領域にまとめる、最も基本的な仕組み。
int[] numbers = { 10, 20, 30 };
2ArrayList とは
配列のように使える、サイズが自動で伸び縮みするリスト。
List<Integer> nums = new ArrayList<>();
3宣言
型を指定して変数を作る。ArrayListは要素の型を<>で指定（ジェネリクス）。
int[] a; List<Integer> b;
4初期化
配列はサイズ固定で一気に作る。ArrayListはnewしてから追加していく。
a = new int[3]; b.add(10); b.add(20);
5要素アクセス
どちらも0から始まるインデックスでアクセスする。
int x = a[0]; int y = b.get(0);
6要素数の取得
配列はフィールド、ArrayListはメソッド。ここが混同しやすい。
int n1 = a.length; int n2 = b.size();
7多次元配列
配列の中に配列を入れる。行×列のような表形式データに使う。
int[][] m = { {1,2,3},{4,5,6} };
8使い分けの目安
項目配列List
サイズ固定可変
速度速いやや遅い
追加削除不可容易
💡配列は「シンプルで高速・サイズ固定」、Listは「柔軟・サイズ可変」。業務コードでは可変長が多いので基本はList。
