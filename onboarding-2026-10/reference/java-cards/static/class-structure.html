Java の基本構造

class と main メソッド、プログラムの「骨格」を読めるようになる
public class Main {
  public static void main(String[] args) {
    System.out.println("Hello");
  }
}
1class
プログラムの設計図となるクラスを定義する。ファイル名とクラス名は一致させる。
2static
クラスに属するメンバーであることを示す。インスタンス化せずに呼び出せる。
3void
戻り値が無いことを示す。mainは値を返さない。
4String[] args
コマンドライン引数を受け取る。実行時に渡された値がここに入る。
5main メソッド
プログラムの開始点（エントリーポイント）。JVMはここから実行を始める。
6public など
アクセスの範囲を指定する。public=どこからでも、private=クラス内だけ。
7{ } ブロック
処理のまとまりを示す。複数の文をひとかたまりとして扱う。
8; セミコロン
文の終わりを示す。1つの処理が終わったことをコンパイラに伝える。
💡クラスの中にmainを作り、その中に処理を書く。読むときはこの骨格から外側→内側の順で追う。
