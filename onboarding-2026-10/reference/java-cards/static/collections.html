コレクションの使い分け

List / Set / Map、何を基準に選ぶか
種類特徴代表実装使う場面
List順序あり、重複OKArrayList一覧表示、処理順が意味を持つデータ
Set順序なし（実装による）、重複NGHashSet重複を除いたID集合、存在チェック
Mapキーと値のペアHashMapIDから名前を引く等、対応関係
1List の代表操作
add/get/size/contains。containsは内部でequalsを呼ぶので、equals未実装だと正しく判定できない。
2Set が重複を防ぐ仕組み
追加時にhashCodeとequalsで同一判定する。両方を正しく実装していないと重複が防げない。
3Map の基本操作
put/get/containsKey/getOrDefault。存在しないキーのgetはnullを返す（例外にならない）。
map.getOrDefault(key, 0);
4拡張for とStream
単純なループは拡張for、集計・変換・絞り込みはStream APIが読みやすい。
list.stream() .filter(v -> v.isActive()) .map(Vehicle::getPlateNo) .toList();
💡「順序が要るか」「重複を許すか」「キーで引きたいか」の3問で、List/Set/Mapはほぼ機械的に決まる。
