オブジェクト指向の大事なとこ

使いやすく・変更しやすく・再利用しやすいプログラムを作るための考え方
1カプセル化
データを隠して安全に使う。フィールドはprivate、外部はpublicメソッド経由でのみ操作する。
2継承
共通の機能を親クラスにまとめ、子クラスが引き継ぐ。関係ない物同士の継承は設計を複雑にする。
3オーバーライド
親のメソッドを子クラスで書き換える。@Overrideを付けて明示する。
class Dog extends Animal { @Override void sound() { ... } }
4ポリモーフィズム
同じ型（親クラス/インターフェース）で、実体ごとに異なる動きをさせる。
Animal a = new Dog(); a.sound(); // Dogの実装が動く
💡4つはセット。カプセル化でデータを守り、継承で共通化し、オーバーライドとポリモーフィズムで柔軟に拡張する。
