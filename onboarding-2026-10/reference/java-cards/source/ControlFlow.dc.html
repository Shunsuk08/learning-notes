演算子と制御構文

分岐とループ、境界値の罠が出やすい場所
1比較・論理演算子
==/!=/</>、&&（かつ）/||（または）/!（否定）。短絡評価（左が確定したら右を評価しない）に注意。
2if / switch
switch式（Java 14+）はbreak不要でアロー構文が書ける。
String kind = switch (n) { case 1 -> "A"; case 2 -> "B"; default -> "C"; };
3for / while
境界値（< と <= の書き間違い）はバグの定番。拡張forはインデックスが要らないときに使う。
for (int i = 0; i < n; i++) { } for (Vehicle v : list) { }
4break / continue
breakはループを抜ける、continueはその回だけスキップして次へ進む。
境界値レビューの着眼点
if (amount < 0 || amount > MAX_AMOUNT) { // 上限ちょうどはOK？境界の両側を確認 throw new IllegalArgumentException(...); }
💡境界値は < と <= の1文字の違いでバグになる。レビューでは「境界ちょうどの値」を必ず自分で代入して確認する。
