関数・メソッドとは

入力→処理→出力、の小さな部品として読む
1基本の流れ
入力（引数）を受け取り、処理をして、出力（戻り値）を返す、の3段階。
2引数と戻り値
method(引数) → 戻り値（return）。呼ぶ側と呼ばれる側の約束。
int add(int a, int b) { return a + b; }
3void とは
戻り値あり（型を書く）/戻り値なし（void）。voidは処理だけして何も返さない。
4使い分け
static＝クラスから直接使う（インスタンス不要）。instance＝newしたオブジェクトから使う。
読解のコツ：呼び出し元を見ればstatic/instanceが分かる
Math.max(1, 2); // クラス名.メソッド → static taxService.registerAll(list); // 変数名.メソッド → instance
💡メソッド名だけ見ても動きは分からない。引数の型・戻り値の型・staticかどうかをセットで読む。
