JDK・JRE・JVM の構造

「開発するのに何がいるの？」を1枚で整理する
JDK（開発に必要）
JRE（動かすのに必要）
JVM
Javaの仮想マシン
java コマンド
JVMを起動する
標準ライブラリ
いつも使う機能
開発ツール
javac（コンパイラ）
jar（圧縮）
javadoc（文書生成）
1JDK とは
JRE と開発ツール群を束ねたもの。「Javaで開発する」なら最低限これが要る。
2JRE とは
JVM・javaコマンド・標準ライブラリの3点セット。「動かすだけ」ならこれで足りる。※Java 11以降、Oracleは単体JREを配布していない（Temurin等は配布あり）。
3開発ツールの中身
javac（.java→.classにコンパイル）、jar（圧縮）、javadoc（ドキュメント生成）。普段使うのは主にjavac。
4標準ライブラリの正体
Java言語本体の機能はごくわずか（if文や四則演算程度）。System.out.printlnやListなど便利機能は、全部ここに入っているクラスファイル。
💡 JDK ⊃ JRE ⊃ JVM。開発するならJDK。実行環境は「JRE相当（JVM＋標準ライブラリ）」があればよい。
